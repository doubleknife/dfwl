# 车队经营管理系统

本仓库按 `AGENTS.md` 和 `/docs` 基线开发，包含 Java 后端、Vue3 管理端和微信小程序。

## 目录

- `docs/`: 需求、设计文档与 OpenAPI 契约
- `database/`: MySQL 基线建库脚本
- `backend/`: Java 后端
- `admin-web/`: Vue3 管理端
- `mini-program/`: 微信小程序

## 当前阶段

阶段 0：项目骨架、数据库迁移、统一响应、异常、日志、鉴权基础。

## Maven

使用 `D:\software\apache-maven-3.9.16\` 下的默认 `settings` 和 `repository`。项目内不要新增 `.mvn/maven.config` 覆盖 Maven 本地仓库。
