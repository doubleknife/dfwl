# R7-V3-A 统一基础模型实施与唯一性复审报告

> 2026-09-30；状态：**V3-A 可关闭（真实 GUI 人工验收 DEFERRED TO V3-R）**。工作区未提交；未开始 V3-B。唯一正式业务规则为 `AGENTS.md` 与 `docs/01～07 V3.0`。`docs/27` 仅用于旧实现定位。

## 实际修改与最终基础模型

- 数据库以 `database/database.sql` 为单一初始化源，生成 Flyway `V1__baseline_schema.sql` 与 H2 测试 schema；旧 V2～V10 增量链退出。无生产数据迁移、兼容表、双写、测试账号或 Secret 初始化。
- `route_template` 仅存客户中文名、货物、起终点、默认含税单价/信息费/司机工资、启停与审计；`transport_task` 保存发布时业务快照、实际单价/信息费、日期与状态；`transport_participant` 唯一保存司机执行、车辆/车挂或外协车牌快照及实际工资。三个金额的变更保留独立历史，重量版本与原始磅单、后续纠错证据分离。
- 唯一任务写入口为 `/route-templates`、`/dispatch-batches/preview|confirm` 和 `/transport-tasks` 动作。司机使用脱敏 `/driver/transport-tasks`；管理端模板/任务/Participant 工资与小程序线路链已切换。旧 `/routes` 写 Controller/Service/Repository、Customer 主数据正式写入口、`driver_salary_entry` 写入、旧动态导入写链、任务 `VOIDED`/void/reactivate 均退出。
- 未发车且未进入转派执行链才允许取消。实际发车后取消被拒；转派由最终当前 Participant 重新发车并卸货；COMPLETED 永久保留。任务实际单价与信息费调整历史、Participant 工资历史均只追加，旧单司机工资表不是可写事实。
- 当前 `PermissionCode`、初始化权限目录和管理员/司机角色授予只含已启用能力；未重建的审批、费用、轮胎、导入、报表、月结权限码暂不植入，后续阶段实现正式端点时再登记。
- 沿用并适配了 V2 已验证的司机/车辆绑定校验、原始磅单、重量版本、附件存储、幂等请求、认证权限、审计与通知基础能力；未重建 V3-B 的完整调度工作台和标准任务 Excel。
