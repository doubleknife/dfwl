# 车队经营管理系统全系统 UI 设计与交互规范 V3.0

本文件是 Web 管理端与微信小程序唯一的公共视觉和交互规范。业务、状态、权限和接口分别遵循 `docs/01～07` 及 `docs/openapi.yaml`；示例布局不能产生新业务入口。新增页面先选用本文件中的公共组件和设计令牌，再补页面专有结构，不复制旧逐页 PNG。

## 1 设计令牌与全局状态

Web 令牌定义于 `admin-web/src/design/tokens.css`，公共呈现于 `admin-web/src/design/ui-final.css` 和 `admin-web/src/style.css`；小程序令牌定义于 `mini-program/design/tokens.wxss`，公共呈现于 `mini-program/app.wxss`。修改共性颜色和尺寸先改令牌，不在页面中建立第二套主题。

| 语义 | Web 当前值 | 小程序当前值 |
| --- | --- | --- |
| 页面／卡片 | `#f4f7f6`／`#ffffff` | `#f4f7f6`／`#ffffff` |
| 正文／次级文字 | `#20312e`／`#64746f` | `#18332e`／`#526d65` |
| 主色／浅底 | `#176f62`／`#e7f4f0` | `#147466`／`#e6f4ef` |
| 危险色 | `#b2352f` | `#b2372e` |
| 卡片／控件圆角 | `8px`／`6px` | `20rpx`／`12rpx` |
| 主按钮 | 高 `38px`、圆角 `8px`、字号 `14px` | 高 `88rpx`、圆角 `16rpx` |

Web 字体为 `Inter, Segoe UI, Microsoft YaHei, system-ui`，默认正文 14px、行高 1.5、数字等宽。间距按 `--ui-space-1/2/3/4/6/8/10` 的 4/8/12/16/24/32/40px 使用。成功、提示、危险、禁用状态使用现有语义令牌；金额负值和危险操作除颜色外还须有文字或图标说明。

加载、空数据、筛选无结果、接口错误、无权限和上传失败分别展示。网络或权限错误不能显示成“暂无数据”；写入时禁用重复点击，成功文案以服务端结果为准。表单字段错误就近呈现，API 错误以业务场景标题、准确中文原因及“确定”按钮显示，层级高于当前编辑弹窗，不展示 SQL、堆栈或请求编号。

## 2 Web 页面骨架与导航

正式页面使用 `admin-web/src/layouts/AppLayout.vue`、`admin-web/src/router/navigationModel.js` 和 `routes.js` 的八域导航：工作台、运输管理、车辆与人员、费用管理、审批中心、工资与考勤、经营与结算、系统设置。一级域可独立展开，菜单自身滚动；二三级用缩进、背景和激活线区分。叶子权限过滤、当前页高亮、祖先展开、面包屑与刷新／后退／直链定位保持一致。工作台“待办概览”是审批与待归属费用权限派生入口，不是独立授权项。无权路由不加载敏感数据。

列表和双栏工作区使用内容区**全部可用宽度**，`ui-page-container` 不设置统一像素上限；费用申请等长表单可用 `ui-form-page` 将阅读宽度限制为 1120px。页面主体不能因宽表产生整页横向滚动。标题与说明使用 `admin-web/src/components/PageHeader.vue`，筛选使用 `FilterBar.vue`；面包屑显示业务层级，不显示 route key。主操作置标题区右侧，窄屏允许换行，不遮挡标题。

常规列表按“标题→筛选→必要汇总或异常→数据表→分页”组织。汇总使用 `SummaryCards.vue`，金额、数量和日期格式统一；财务汇总以正式 API 为准，不在前端重算。详情用摘要、业务分区、证据和历史层级组织；技术 ID 不作为主列表的唯一可读名称，任务选择显示日期与线路等业务信息。

## 3 按钮、表单和选择器

五类操作沿用同一视觉语义：主操作用于保存、提交、确认和同意；次操作用于取消、选择文件、刷新和下载；返回导航用轻量文字；详情入口用轻量文字或描边和右箭头；停用、撤回、冲销和解绑等危险操作用危险色并保留业务确认。同一操作区优先一个实心主按钮。Web 样式使用 `button.primary`、`.ui-return-button`、`.ui-detail-button`、`.ui-danger-button`，小程序使用 `button.primary`、`button.secondary`、`.mp-return-button`、`.mp-detail-link`／`.mp-detail-button`、`.mp-danger`。按钮的 hover／按下、键盘焦点、禁用和加载状态要可辨；外观不改变权限、点击目标或状态机。

表单使用永久 Label、必填说明、单位、就地错误与提交中的禁用状态。Web 简单编辑使用 `FormDialog.vue`，字段多或需历史对照时使用 `DetailDrawer.vue`；实体查找优先复用 `EntityPicker.vue`，保留原数据范围、分页和远程搜索语义。小程序下拉选择统一使用 `mini-program/components/search-select/`：底部弹层、标题、关闭、本地搜索、独立滚动列表、已选标识和空态；搜索仅按已加载选项的显示文字做包含匹配，不因键入搜索词请求后端。value／ID、默认值、必填、禁用、清空和原有联动保持原业务含义。日期、时间和上传不替换成下拉组件。

## 4 表格与分页

正式服务端分页列表使用 `admin-web/src/components/DataTable.vue` 的 `ui-paged-table` 布局和 `PaginationBar.vue`。表格高度随视口可用空间变化，表头固定，数据区在表格容器内纵向滚动，横向溢出也只留在表格容器内；分页栏位于表格底部，不被数据行推到整页下方。加载、空态和错误后仍保持可操作高度，不遮挡底部按钮。金额与计数右对齐，状态使用中文标签。

每页可选 **10、20、50、100** 条，默认 20。切换条数保留筛选、重置到第 1 页、按新 `pageSize` 请求服务端并滚动回表格顶部；切页同样重置滚动。总数和总页数来自服务端，不截取当前单页数据冒充服务端分页。月度出勤网格、调度草稿、导入预览、审批节点编辑、详情抽屉及图表使用适合自身的滚动容器；有正式分页表格时仍尽量保持同一分页交互。角色权限目录是只读完整目录，独立滚动而不伪装服务端分页。

## 5 弹窗、抽屉、证据和导入

弹窗有明确业务标题、关闭入口、可读错误和稳定操作区；长内容仅在正文滚动。详情抽屉的标题固定、正文独立滚动，宽度随业务内容和视口适配，不能让费用表格横向滚动遮住金额和操作。危险确认说明后果，提交时防重复；打开新详情不覆盖未提交表单。申请与审批图片使用统一附件中心的多图缩略图、预览、逐张移除和上传失败提示；小程序支持相机与相册，上传中禁止提交。历史图片分别随 Submission Version 和 Approval Action 留存，显示分组不混淆。

任务、轮胎和充电的正式 Excel 导入沿用各自 API 与事务规则，但文件选择、预览／确认、结果卡片、全部／通过／失败筛选及历史详情采用一致外观，可复用 `ImportTabs.vue`、`DataTable.vue` 和 `DetailDrawer.vue`。上传成功不等于正式入账，预览不写正式事实；确认后显示真实总数、成功和失败结果，按各业务规则清除旧预览。司机车辆十列初始导入使用宽弹窗、独立滚动的预览表及整批确认，不新建导入历史。

**DAILY 费用 Excel 是独立的填表交互**：Web 上传固定模板后将行追加进同一可编辑费用明细表，可与手工行混合；它不套用正式导入批次或产生费用事实。TASK 继续单笔。小程序 DAILY/TASK 每次均一笔且无 Excel 入口。费用申请和审批凭证统一为多图，不因切换图片或返回页面清空未提交表单。

## 6 审批与小程序

审批中心的“我的待办”“我的申请”“审批记录”“流程与模板配置”是独立入口；审批详情显示发起人、发起时间、当前角色、提交版本、申请附件和处理时间线。当前节点按冻结资格显示通过、合法打回；有撤回资格的申请人可在同一操作区看到撤回，按钮显隐不代替后端校验。费用、换胎和普通审批详情使用相同附件预览、历史和错误规范。

小程序使用 `mini-program/design/tokens.wxss`、`mini-program/app.wxss` 和各页面 WXSS。主要触控按钮不低于 88rpx，选择项不低于约 92rpx；底部选择面板随视口与键盘调整，搜索输入框和结果不被键盘遮挡，结果列表独立滚动。司机任务卡片突出日期、线路、地点、真实车牌、状态和下一步，不以编码代替业务名称；司机端不展示无权经营字段。拍照、上传、弱网和返回页面应保留已有输入，错误与重试清晰可见。

## 7 响应式与新增页面验收

Web 至少核对 1366×768 和 1920×1080：页面主体不横向溢出，表头与分页可见，表格内容独立滚动，弹窗／抽屉不遮挡操作。窗口缩放后重新计算可用高度，避免双重纵向滚动。小程序核对常见手机尺寸及键盘弹起后的表单、选择器和底部操作区。颜色和尺寸以实际令牌与当前公共组件为准；旧逐页设计图不构成当前页面或权限清单。

新页面应先登记正式路由和页面／按钮权限，再选择 PageHeader、FilterBar、SummaryCards、DataTable、PaginationBar、FormDialog、DetailDrawer、ImportTabs、EntityPicker 或小程序 SearchSelect 中适合的组件。只在业务确实不同且现有组件无法表达时新增页面专有布局；不得为同一选择或导入行为复制第二套状态管理。新增页面须覆盖权限过滤、Loading、Empty、Error、无权限、禁用、键盘与响应式，并按 `docs/07` 分别记录自动和人工验收结果。
