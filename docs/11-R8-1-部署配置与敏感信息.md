# R8-1 部署配置与敏感信息

本阶段只准备配置，不安装或启动 Ubuntu 服务。Maven 仅从 `backend/src/main/resources/application.yml` 打包基础配置，不再维护第二份同名打包配置。提交到 Git 的配置只能保存非敏感默认值与环境变量占位符；真实数据库密码、腾讯云 SecretId/SecretKey 不得进入 Git、JAR、Java、前端 `VITE_*` 或小程序。生产环境修改 JAR 外的私有配置文件，不修改 JAR 内配置。

## 本机开发

可把私有配置放在仓库外，或放在已被 Git 忽略的 `.runtime/application-local.yml`。`.runtime` 不在 Maven resources 内；不要把私有文件移回 `backend/src/main/resources`。启动时显式传入外部路径，例如在仓库根目录执行：

```text
java -jar backend/target/fleet-ops-backend-0.0.1-SNAPSHOT.jar --spring.config.additional-location=file:./.runtime/application-local.yml
```

外部文件按实际需要覆盖 `spring.datasource.url`、`spring.datasource.username`、`spring.datasource.password`、`fleet.ocr.provider`、`fleet.ocr.tencent.secret-id`、`fleet.ocr.tencent.secret-key`、`fleet.ocr.tencent.region` 和 `fleet.storage.local-root`。本机测试库和照片路径只能留在本机配置或测试进程环境中。真实 OCR 集成测试仅在显式提供 `FLEET_OCR_TENCENT_SECRET_ID`、`FLEET_OCR_TENCENT_SECRET_KEY`、`FLEET_OCR_TENCENT_REGION`、`TEST_TENCENT_OCR_IMAGE_PATH` 时调用腾讯云。

## 未来 Ubuntu 配置

可以复制 `deploy/env/dfwl.env.example` 到 `/etc/dfwl/dfwl.env`，填入实际值，归服务账号所有并限制为 `0600`；systemd unit 可使用 `EnvironmentFile=/etc/dfwl/dfwl.env`。也可以在服务器创建 `/etc/dfwl/application.yml`，写入所需数据库和 OCR 配置，并以 `--spring.config.additional-location=file:/etc/dfwl/application.yml` 启动，使外部文件覆盖 JAR 内默认值。两种私有配置均不得提交；修改生产配置时只改服务器外部文件。环境变量方式所需键：

| 配置 | 用途 |
| --- | --- |
| `SPRING_PROFILES_ACTIVE=prod` | 启用生产存储与 OCR 必需配置 |
| `FLEET_DB_URL`、`FLEET_DB_USERNAME`、`FLEET_DB_PASSWORD` | MySQL 连接；Flyway 使用同一 DataSource |
| `FLEET_STORAGE_ROOT` | 持久附件目录，如 `/data/dfwl/files`；须可写并纳入备份 |
| `FLEET_OCR_PROVIDER` | 生产示例为 `TENCENT` |
| `FLEET_OCR_TENCENT_SECRET_ID`、`FLEET_OCR_TENCENT_SECRET_KEY` | 仅服务端使用的腾讯云凭据 |
| `FLEET_OCR_TENCENT_REGION` | 可省略，默认 `ap-guangzhou` |
| `FLEET_SERVER_PORT` | 可省略，默认 `8080` |
| `FLEET_FLYWAY_ENABLED` | 可省略，默认启用；正式部署不应关闭 |

数据库连接没有内置账号或密码。生产 profile 缺少存储路径会启动失败；选择腾讯云 OCR 而缺少 SecretId/SecretKey 也会在启动时失败，错误信息不包含凭据。不要使用 root、测试库、Windows 路径或临时目录作为生产配置。`/actuator/health` 可用于健康检查，其他敏感 Actuator 端点不开放。

管理端开发使用同源 `/api/v1` 与 Vite 本地代理；生产构建也使用 `/api/v1`，由未来的 Nginx 转发到 Spring Boot。`VITE_*` 会写入浏览器构建产物，绝不能存放 Secret。小程序的 API 地址在公开配置中按开发、体验和正式版本设置；发布前须填入获准使用的 HTTPS 域名，小程序包内不得包含数据库或 OCR 凭据。

已提交的历史配置含本机开发/测试数据库密码，仅供本机使用。Ubuntu 测试服务器必须创建全新的独立随机密码，未来生产环境再次使用另一套独立密码，均不得复用历史密码。本阶段不改写 Git 历史，也不强制轮换当前本机测试密码。V2 默认管理员 Seed 仍按既定设计保留，首次登录后应修改密码。
