# V3.0 全局按钮视觉规范

本规范适用于管理端和微信小程序的正式页面。按钮视觉按操作意图区分，不改变事件绑定、权限、确认流程或业务状态。正式页面交互以 `docs/05-页面交互与状态设计说明书_V3.0.docx` 为准。

| 类别 | 用途 | 视觉与位置 | 代码入口 |
| --- | --- | --- | --- |
| 主操作 | 保存、提交、确认导入、同意审批、发车和卸货 | 深墨绿色实心、白字；同一操作区优先一个，放在操作区右侧或移动端宽按钮 | Web `button.primary`；小程序 `button.primary` |
| 次操作 | 取消、下载、选择文件、刷新、加载更多 | 白色或浅色底、细边框、深色字；与主操作同一尺寸体系 | Web 普通 `button`；小程序 `button.secondary` |
| 返回导航 | 返回列表、上一层 | 左箭头加简短文案，轻量无突出胶囊；靠近页面标题。小程序原生导航可准确返回时避免重复 | Web `.ui-return-button`；小程序 `.mp-return-button` |
| 详情入口 | 查看详情、申请记录、处理历史、业务附件 | 轻量文字或描边，文案后有右箭头；小程序列表整行可点、提示靠右 | Web `.ui-detail-button`；小程序 `.mp-detail-link`、`.mp-detail-button` |
| 危险操作 | 停用、撤回、冲销、删除、解绑 | 红字或红色描边；原有确认与业务校验不变 | Web `.ui-danger-link`、`.ui-danger-button`；小程序 `.mp-danger` |

管理端按钮基础高度 38px、圆角 8px、字号 14px、水平内边距 14px；图标尺寸 16px。小程序基础触控高度 88rpx、圆角 16rpx、字号约 30rpx。两端使用同一深绿色与危险红色语义，具体值由 `admin-web/src/design/tokens.css`、`admin-web/src/design/ui-final.css` 和 `mini-program/design/tokens.wxss`、`mini-program/app.wxss` 维护。表格内轻量详情入口及导航、页签、图标按钮可按所在容器保持紧凑，但不能缩小小程序的主要触控区域。

正常、hover 或按下、键盘聚焦、禁用和加载状态需可区分。禁用时保留原 `disabled` 条件；已有 Loading 文案与微信按钮加载指示保持原样。公共样式只作用于按钮及明确标记的详情入口，不覆盖输入框、选择框、状态标签或普通文本。

审批详情的业务返回入口仍回到原审批列表；小程序审批卡片的“查看详情”仍打开完整申请内容、凭证和处理记录。所有查看入口、危险操作及主操作只调整外观，不增加或删除业务动作。
