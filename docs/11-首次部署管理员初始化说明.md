# 首次部署默认管理员说明

系统首次部署时，Flyway `V2__default_admin_seed.sql` 与 `database/database.sql` 会初始化系统权限、固定 `ADMIN` 角色、ADMIN 的全部权限关系及默认管理员账号。两份 SQL 的 Seed 内容保持一致，所有插入均依赖唯一键和 `INSERT IGNORE` 保证重复执行不会产生重复数据，也不会覆盖已修改的管理员密码。

## 默认登录信息

- 登录手机号：`13900000001`
- 初始密码：`Dfwl@Fleet2026!`
- 角色：`ADMIN`

**首次登录后必须立即通过现有“修改密码”功能更换初始密码。** 系统不新增强制改密流程，由部署和运维人员负责完成首次改密。

数据库中仅保存由项目当前 `BCryptPasswordEncoder` 生成的 BCrypt 哈希，不保存初始密码明文。初始密码只用于首次交付，禁止将修改后的真实密码提交到源码、SQL、配置或部署脚本仓库。

## 初始化结果

空库执行 Flyway 后应存在：

1. `PermissionCode` 当前定义的全部权限；
2. 固定且启用的 `ADMIN` 角色；
3. ADMIN 与全部权限的关联；
4. 一个启用的默认管理员；
5. 默认管理员与 ADMIN 的角色关联。

重复启动应用不会重复执行 Flyway migration；即使 Seed SQL 被人工重复执行，唯一键和 `INSERT IGNORE` 也会阻止重复角色、权限、用户和角色权限关系，并保留首次登录后修改的新密码。
